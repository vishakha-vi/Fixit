🛡️ Core FixIt Invariants Matrix

  • 🟢
    Single Green State Invariant:
    Only VERIFIED_FIXED is rendered Green. REPORTED_FIXED is strictly rendered Amber with warning cues.
  • ⏱️
    Sole Time Authority:
    Every timestamp and SLA calculation is governed by apps.core.clock.now(). Direct datetime.now() is statically forbidden.
  • 🔒
    Anti-IDOR Enumeration:
    Unauthorized requests to other residents' tickets return 404 Not Found rather than 403 to prevent ID probing.
  • 📦
    Zero-CDN Offline Independence:
    WhiteNoise serves locally vendored Bootstrap 5 & HTMX. The entire campus application functions without internet egress.
